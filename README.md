# 📊 Sales & Business Analytics Dashboard

A BCA portfolio project using **Excel, SQL/MySQL and Power BI** to analyze sales data, identify business trends and visualize key performance indicators.

## 📌 Included

- 150 realistic sample sales records
- Professional Excel workbook with formatted data and summary sheet
- CSV dataset for database import
- MySQL table and analysis queries
- Power BI dashboard setup guide
- Business analytics and KPI analysis

## 📊 Dashboard

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 Products
- Interactive Date Slicer
- Interactive Category Slicer
- Interactive Region Slicer

## 🛠️ Technologies Used

- Business Analytics
